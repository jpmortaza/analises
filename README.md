## Portal de Notícias

Projeto simples de portal de notícias em PHP + MySQL.

### Configuração
1. Crie um banco de dados MySQL chamado `portal` e execute o script `db.sql`.
2. Ajuste as credenciais em `config.php` se necessário.
3. Faça o deploy dos arquivos em um servidor com PHP.
4. Acesse `admin/login.php` com usuário `admin` e senha `admin` para gerenciar as notícias.
